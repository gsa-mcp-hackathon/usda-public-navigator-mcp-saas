# GSA Hackathon Deliverables

Version 1.0 · 2026-11-23 · Folder index · [Repository README](../README.md)

This folder holds the three submission deliverables for the GSA MCP Server and SI Agent Government Hackathon, in one place. The code, evaluation data and documentation they refer to are in the rest of this repository.

## What is here

| File | What it is | Read it for |
| :-- | :-- | :-- |
| `USDA-MCP-SaaS-Deck-GSA-Client-Experience-Final.pdf` | The submission slide deck. | The problem, the six design decisions and their business outcomes, the demonstration, the evaluation results and the lessons learned. |
| `EVALUATION-DOCUMENT-v2.3-USDA.pdf` | The evaluation document, version 2.3, 23 November 2026. | Testing method, results, security considerations and lessons. The same content as `eval/` in this repository. |
| `USDA-MCP-SaaS-Eligibility-V3.mp4` | The recorded demonstration. | One user conversation shown next to the platform trace behind it. |

## Suggested reading order

1. The deck, for the story.
2. The video, for the demonstration.
3. The evaluation document, for the evidence behind both.

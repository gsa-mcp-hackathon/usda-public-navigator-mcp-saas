# Registries

> Version 1.0 · Updated 2026-11-21 · Folder index  
> [Documentation index](../docs/README.md) · [Repository README](../README.md)

The published definitions a Core loads: attribute schemas, contracts and the public dataset registry.

| Folder or file | What it is |
|---|---|
| `schemas/` | Versioned attribute and request schemas, such as the core and Eligibility profile and program schemas and the requirements-package request and response schemas |
| `public-catalog-v1.schema.json` | The public catalog contract |
| `public-datasets-v1.json` | The registry of public datasets, with record limits and de-duplication rules |
| `source-primer/` | The first batch of candidate sources and the result of probing them |

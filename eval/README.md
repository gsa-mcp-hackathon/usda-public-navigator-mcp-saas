What is here, and the order to read it. The tests prove the platform works; they are not every test written to build it. Read the three documents in order (1 to 3), then the recorded runs.

| Read | What it is |
|---|---|
| 1. [EVALUATION-DOCUMENT.md](EVALUATION-DOCUMENT.md) | The evaluation document, for readers who are not engineers: how it fits with the repository and the slide deck, how the tests were designed and why, results by claim, security, lessons, and a guide to where each test lives and how to read the saved evidence. Start here |
| 2. [EVIDENCE-SUMMARY.md](EVIDENCE-SUMMARY.md) | The summary: tests by type, recorded results, platforms, limits |
| 3. [PERFORMANCE-REPORT.md](PERFORMANCE-REPORT.md) | How fast the platform answered in the recorded runs, in plain terms |
| 4. [results/](results/README.md) | The recorded runs and the verifier that checks them. The final 23 November agent evaluation is in [results/phoenix-agent-eval/](results/phoenix-agent-eval/README.md) |
| [datasets/](datasets/README.md) | The 23 questions with expected answers, in three sets |
| [synthetic-datasets/](synthetic-datasets/README.md) | 23 fictional people with starter profiles and expected outcomes |
| [operator/](operator/README.md) | The script engine and the machine suites |
| [`INSTRUCTIONS-USED.md`](INSTRUCTIONS-USED.md) | The agent instructions used on each platform |
| [`MAPPING-PROMPT.md`](MAPPING-PROMPT.md) | The instructions that map a program's cited requirements to typed criteria |

The method behind these is in [the evaluation guide](../docs/EVALUATION.md).
